# E-Commerce Sales Analytics Dashboard

## Project Overview

This project presents an interactive **E-Commerce Sales Analytics Dashboard** created using **Microsoft Power BI**. The dashboard analyzes sales performance and provides useful insights into revenue, orders, products, regions, payment methods, customer ratings, and delivery performance.

##  Objective

The main objective of this project is to analyze e-commerce sales data and create an interactive dashboard that helps stakeholders understand business performance and make data-driven decisions.

##  Dataset

The dataset contains **5,000 e-commerce transaction records**.

### Key Columns

- Order ID
- Order Date
- Product Category
- Region
- Quantity
- Unit Price
- Discount
- Payment Method
- Delivery Days
- Customer Rating
- Revenue

##  Tools Used

- Microsoft Power BI
- Microsoft PowerPoint
- CSV Dataset

##  Dashboard Features

- Total Revenue KPI
- Total Orders KPI
- Total Quantity KPI
- Average Customer Rating KPI
- Average Delivery Days KPI
- Revenue Trend Analysis
- Sales by Product Category
- Sales by Region
- Revenue by Payment Method
- Top Products Analysis
- Customer Rating Distribution
- Revenue and Quantity Analysis
- Interactive slicers for Region, Product Category, and Year

##  Key Insights

- The dashboard provides an overview of overall e-commerce sales performance.
- Revenue can be analyzed across different product categories and regions.
- Payment methods can be compared based on their contribution to revenue.
- Top-performing products can be identified using revenue analysis.
- Customer ratings provide an overview of customer satisfaction.
- Interactive slicers allow users to explore the data based on different filters.

##  Dashboard Preview

The Power BI dashboard provides an interactive visual representation of the e-commerce sales data.

##  Conclusion

The E-Commerce Sales Analytics Dashboard provides a simple and interactive way to understand sales performance. Power BI was used to transform the raw data into meaningful visualizations and KPIs that can support data-driven business decisions.
